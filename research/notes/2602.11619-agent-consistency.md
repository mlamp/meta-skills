# When Agents Disagree With Themselves: Behavioral Consistency in LLM Agents

- arXiv:2602.11619v1 [cs.AI] · Aman Mehta (Snowflake) · 2026-02-12 · retrieved 2026-07-21
- https://arxiv.org/abs/2602.11619
- One line: same agent, same task, ten runs → 2–4 distinct action paths; consistency strongly predicts correctness, so single-run evals are unreliable.

## What they did

- ReAct agent with three tools (search / retrieve / finish) on 100 hard HotpotQA questions × 10 runs × 3 models (Llama 3.1 70B, GPT-4o, Claude Sonnet 4.5), temperature 0.7 — 3,000 runs.
- Metrics: answer consistency, unique action sequences per task, step variance ratio, first divergence point.

## Numbers that matter

- Unique action sequences per 10 identical runs: Sonnet 4.5 2.0 · GPT-4o 2.4 · Llama 3.1 70B 4.2.
- Consistent tasks (≤2 unique paths) score 80–92% correct; inconsistent tasks (≥6) score 25–60%. Gap: 32–55pp depending on model.
- 69% of divergence happens at step 2 — the first real decision.
- Short paths (~3 steps) ≈ 90% correct; long paths (8+) ≈ 43%; steps vs correctness r = −0.34.
- Temperature 0.7 → 0.0 (Llama, n=20): unique paths 4.2 → 2.2, accuracy +5.4pp. Variance persists even at 0.0.

## Use for skill #1

- This shapes our eval method, not skill content: every recorded score = N repeated runs + variance, never a single run (C10, C11).
- Consistency is itself a metric: does a skill reduce path variance on its target tasks?
- First-decision dominance → the trigger / when-to-use section of a skill deserves outsized review weight (C12).
- Run judge passes at low temperature.

## Caveats — why this stays unproven

- One benchmark (HotpotQA), toy lexical tools, three models; the temperature ablation is n=20 on one model.
- Single-author preprint.
- Minimal ReAct framework — real harnesses like ours differ a lot.
